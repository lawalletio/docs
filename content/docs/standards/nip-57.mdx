---
title: NIP-57 · Zaps
description: Asynchronous payment verification. A signed receipt is published to Nostr relays.
---

import { Flow } from '@/components/flow';

The payer sends a signed zap request (kind `9734`) to the pay callback. Once paid, the recipient's server publishes a zap receipt (kind `9735`). Anyone listening on the relays sees it, so nobody has to poll.

<Flow steps={[['Payer', 'callback?nostr=9734'], ['Platform', 'BOLT11'], ['Payer', 'pays'], ['Platform', 'kind 9735'], ['Relays']]} />

**In LaWallet:** pay responses set `allowsNostr` and `nostrPubkey`, and the platform signs the receipts.

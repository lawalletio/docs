A Boltcard is an NTAG424 DNA chip whose [NDEF](/docs/standards/ndef) URL changes on every tap (SUN). Each read gives `lnurlw://…?p=…&c=…`:

- `p`: the card UID and a tap counter, encrypted.
- `c`: a MAC proving the card made it.

The server decrypts `p`, checks `c` and that the counter went up (no replays), then answers with an [LUD-03](/docs/standards/lud-03) withdraw.

**In LaWallet:** the platform issues and manages cards, the POS charges them, and the wallets can read them too.

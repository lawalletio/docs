title: Android Reader Mode
description: The open app gets every tap directly, with no system chooser.
---

import { Flow } from '@/components/flow';

`NfcAdapter.enableReaderMode()` hands each tag straight to the foreground app. While it's on, the phone only reads: card emulation is off, so two phones can't both play "tag".

<Flow steps={[['Card / sticker / POS', 'tag'], ['Wallet (reader mode)', 'NDEF URL'], ['LNURL or BOLT11']]} />

**In LaWallet:** the Android wallet turns it on while open and reads Boltcards, stickers and POS invoices. The POS uses it to read cards. On iOS the wallet does the same with a Core NFC NDEF reader session.

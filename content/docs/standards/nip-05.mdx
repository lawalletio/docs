---
title: NIP-05 · Identity
description: name@domain maps to a Nostr public key.
---

`GET https://domain.com/.well-known/nostr.json?name=alice` returns `{ "names": { "alice": "<pubkey>" } }`. Clients show `alice@domain.com` as verified.

**In LaWallet:** the platform serves it, so a user's Nostr identity and [lightning address](/docs/standards/lud-16) share the same name.
